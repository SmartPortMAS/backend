## 3. 부두 제원 특기사항 (입항정보 기준)

- 대한유화: 안벽 481m(입항정보), 수심 북단 14m/남단 12.5m, DWT 북단 80,000/남단 50,000, 취급 오일/케미칼/가스. (805 시설현황은 320m로 표기, 값 차이 있음)

- 효성: 단선석 240m, 수심 12, 30,000, 케미칼. 단독선석이라 막히면 정박지 대기 확정.
- 한국석유공사: 원유 BUOY 단독, 수심 40m, 최대 325,000, 원유.
- 온산탱크터미널: 온산 1,2부두 유류(벙커C유, 등유, 경유, 휘발유), 각 20,000, 수심 11. 좌표 35-26.20N 129-21.28E. (별도 유류 시설, 필요시 추가)

## 4. 게이트 (안전 에이전트 반영 대상)

- 검사 요구사항(3.2): 전 터미널 공통으로 SIRE(유조선)/CDI(케미칼,LPG) 검사 이력 요구. R1, R2 하드블록이 온산 전체에 적용됨을 확인.
- 한국석유공사 부이: 긴급 이안 조건 명시. 40톤 이상 계류력 초과가 10분내 3회 지속 발생 시 긴급 이안. 부이 전용 게이트.
- 벤젠 특별취급(9.18), H2S(9.19): 정일/오드펠에서 확인. 벤젠 5% 초과 화물은 이전화물 벤젠프리 증명 필요(R15).
